# Site do AbaTraço
Projeto estático para a Vercel. Não requer instalação, build, Firebase ou banco de dados.

## Publicar
Extraia o ZIP. Envie a pasta que contém index.html no Vercel Drop, em https://vercel.com/drop.
Também é possível importar o código de um repositório no painel da Vercel usando o preset Other, com a raiz do site apontando para a pasta que contém index.html.
Use o endereço público de produção mostrado depois da publicação.

## Campos da Chrome Web Store
- URL da página inicial: https://SEU-PROJETO.vercel.app/
- URL do suporte: https://SEU-PROJETO.vercel.app/suporte/
- Política de privacidade: https://SEU-PROJETO.vercel.app/privacidade/
- URL oficial: selecione o endereço depois de verificar a propriedade do site no Google Search Console.

O botão da página inicial abre a busca pelo nome do AbaTraço. Quando a listagem for publicada, você pode substituir a URL de busca em index.html e em suporte/index.html pelo link direto da extensão.
